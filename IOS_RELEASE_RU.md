# Выпуск UneBil для iPhone

Проект iOS уже добавлен в каталог `ios/`. Основной Flutter-код общий для
Android и iPhone, а локальные уведомления настроены отдельно для обеих
платформ.

## Что понадобится

- Mac с актуальными macOS и Xcode 26 или новее;
- актуальный Flutter stable;
- Apple ID;
- членство Apple Developer Program для TestFlight и App Store;
- физический iPhone для проверки уведомлений.

С Windows можно редактировать Flutter-код и запускать общие тесты, но собрать,
подписать и загрузить `.ipa` нельзя: для этого нужны Xcode и macOS.

## 1. Подготовка на Mac

Скопируй или клонируй проект на Mac и выполни из корня проекта:

```sh
flutter doctor -v
flutter pub get
dart run flutter_launcher_icons
open ios/Runner.xcworkspace
```

Текущая версия iOS-проекта использует Swift Package Manager. Если будущая
зависимость потребует CocoaPods, Flutter или Xcode сообщит об этом отдельно.

## 2. Подпись в Xcode

В Xcode открой `Runner` → `TARGETS: Runner` → `Signing & Capabilities`:

1. включи `Automatically manage signing`;
2. выбери свою команду в поле `Team`;
3. проверь Bundle Identifier: `com.ibrashov.unebil`;
4. если этот идентификатор уже занят в Apple, замени его на уникальный, например
   `kz.<твое-имя>.unebil`, и используй тот же идентификатор в App Store Connect;
5. оставь минимальную версию iOS 13.0 или повысь её при необходимости.

Проект настроен как приложение только для iPhone, поэтому отдельные iPad-
скриншоты для этой версии не требуются.

Версия приложения берётся из `pubspec.yaml`: `1.0.0+1`. Часть после `+` — номер
сборки. Для каждой следующей загрузки в App Store Connect увеличивай его.

## 3. Проверка на настоящем iPhone

Подключи iPhone к Mac, выбери его как устройство запуска и нажми Run. Проверь:

- первый запуск и выбор языка;
- добавление темы и получение фактов через `https://unebil.onrender.com`;
- запрос разрешения на уведомления;
- тестовое уведомление через 15 секунд, в фоне и при открытом приложении;
- открытие нужного факта по нажатию на уведомление;
- светлую и тёмную тему;
- русский, казахский и английский интерфейс;
- работу после полного закрытия и повторного запуска приложения.

Локальные уведомления в iOS имеют системное ограничение на число ожидающих
уведомлений. UneBil планирует не более 48, поэтому остаётся ниже лимита iOS.

## 4. App Store Connect

В Apple Developer зарегистрируй явный App ID с тем же Bundle ID. Затем в App
Store Connect создай новое приложение для iOS и подготовь:

- название, подзаголовок, описание и ключевые слова;
- URL поддержки и URL политики конфиденциальности;
- категорию, возрастной рейтинг и страны распространения;
- скриншоты требуемых размеров iPhone;
- ответы App Privacy: приложение хранит темы и факты локально, но введённая
  тема отправляется на backend UneBil и далее используемому AI-провайдеру;
- контактные данные для App Review и пояснение, что вход в аккаунт не нужен.

Политика конфиденциальности должна точно описывать передачу пользовательской
темы backend-сервису и AI-провайдеру. Не отмечай данные как «не собираемые»,
пока фактическая обработка backend и журналы хостинга не проверены.

## 5. Сборка и TestFlight

Из корня проекта на Mac выполни:

```sh
flutter analyze
flutter test
flutter build ipa --release \
  --dart-define=API_BASE_URL=https://unebil.onrender.com
```

Архив появится в `build/ios/archive/`, а IPA — в `build/ios/ipa/`. Его можно
загрузить через Xcode (`Window` → `Organizer` → `Distribute App`) или приложение
Transporter. Сначала выпусти сборку во внутренний TestFlight, проверь её на
нескольких iPhone, затем отправляй эту сборку на App Review.

## Перед отправкой на проверку

- production-backend доступен по HTTPS и стабильно отвечает;
- в приложении нет тестовых текстов, битой кодировки и заглушек;
- иконка и стартовый экран проверены на устройстве;
- номер сборки уникален;
- заполнены App Privacy и политика конфиденциальности;
- приложены актуальные скриншоты;
- TestFlight-сборка протестирована на физическом iPhone;
- в Review Notes объяснено назначение AI-генерации и уведомлений.
