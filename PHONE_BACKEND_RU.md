# Как запустить UneBil на физическом телефоне

Backend не должен находиться внутри телефона. В нём хранится секретный AI-ключ,
поэтому обычно он работает на компьютере для тестирования или на отдельном
HTTPS-сервере для постоянного использования.

## Быстрый запуск через домашний Wi-Fi

1. Запусти backend на компьютере:

   ```powershell
   cd backend
   npm start
   ```

2. Подключи компьютер и телефон к одной обычной Wi-Fi сети. Гостевая сеть не
   подходит. На телефоне должен появиться значок Wi-Fi, а не только `4G+`.

3. Из корня проекта собери APK:

   ```powershell
   .\scripts\Build-PhoneApk.ps1
   ```

   Скрипт сам определит локальный IP компьютера, проверит `/health` и создаст
   `UneBil-phone-release.apk`.

4. Перед запуском приложения открой на телефоне адрес, который напечатал скрипт.
   Для текущей сети это:

   ```text
   http://192.168.0.7:3000/health
   ```

   Правильный ответ: `{"ok":true}`.

Компьютер и backend должны оставаться включёнными. Если IP компьютера изменился,
APK нужно пересобрать этим же скриптом.

## Работа через 4G/5G и любой Wi-Fi

Для этого backend нужно разместить на постоянно работающем публичном сервере с
HTTPS. После развёртывания APK собирается так:

```powershell
.\scripts\Build-PhoneApk.ps1 -ApiBaseUrl https://your-backend.example.com
```

AI-ключ хранится только в переменных окружения сервера. Его нельзя добавлять во
Flutter-код или APK. Перед публикацией backend также нужно защитить авторизацией,
лимитами запросов и квотой, иначе посторонние смогут расходовать AI-баланс.
